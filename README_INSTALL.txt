================================================================================
                    SmartKhata Desktop — Installation Guide
================================================================================

SmartKhata (স্মার্টখাতা) is a 100% offline, native desktop bookkeeping and 
inventory management software for retail and wholesale businesses.

NO EXTERNAL DEPENDENCIES:
- No JDK / Java installation required (bundled embedded Java 21 LTS runtime).
- No MySQL, XAMPP, or database server required (bundled embedded SQLite 3.47).
- No internet connection required (runs fully offline).

--------------------------------------------------------------------------------
HOW TO INSTALL:
--------------------------------------------------------------------------------
1. Double-click "SmartKhata-Setup.exe".
2. Select your preferred installation options (Desktop shortcut, Start menu).
3. Click "Install" and wait for the files to unpack.
4. Click "Finish" to launch SmartKhata immediately!

--------------------------------------------------------------------------------
DATA LOCATION & UNINSTALL SAFETY:
--------------------------------------------------------------------------------
- All your business records, customer dues, stock ledgers, and transactions
  are stored securely in your Windows user profile at:
  %LOCALAPPDATA%\SmartKhata\data\smartkhata.db

- If you uninstall or upgrade SmartKhata in the future, your business database
  at the location above is NEVER deleted. Your financial records remain safe.

--------------------------------------------------------------------------------
