SMARTKHATA — CUSTOMER PAGE PNG ASSET PACK
=========================================
Based on the latest Customers & Baki Khata grocery-themed dashboard mockup.

FOLDERS
- illustrations/: Reusable grocery artwork (transparent PNG extracted from the closely matched preceding dashboard design).
- icons/navigation/: Clean transparent PNGs of the menu/navigation icon set.
- icons/customer_page/: Clean transparent PNG icons for customer details, ledger, dues and actions.
- icons/colored_tiles/: Matching soft-background customer/finance icon tiles.
- branding/: Grocery store marks on transparent backgrounds.
- source_crops/: Exact pixel crops from the latest customer-page mockup (these include their original UI background; they are not standalone transparent vector objects).
- reference/: The complete latest customer-page screenshot as an implementation reference.

PNG EXPORT INFO
All files are PNG. Recreated outline icons are 192x192, colored tile icons are 256x256, and grocery artwork retains its source or 2x dimensions. Transparent assets are RGBA, while exact screenshot crops preserve surrounding pixels.

NOTE
The supplied UI was a single flattened raster image, not a layered design source.
Icons in this pack are carefully redrawn/reused rather than exact editable native layers from the screenshot. The pale illustration in the new banner cannot be perfectly separated from its blended background, so its exact source crop is included alongside a reusable basket illustration from the previous dashboard design.
