SMARTKHATA — SUPPLIERS & PAONA KHATA — PNG ASSET PACK
=======================================================
This bundle is prepared from the latest green-and-white Suppliers page mockup.

FOLDERS:
• illustrations/            Reusable transparent grocery-bag art and a redrawn supplier-specific cartons/produce/rice illustration (standard + 2x)
• branding/                 SmartKhata grocery-store mark on transparent backgrounds
• icons/navigation/         10 transparent menu icons, active suppliers shown in green
• icons/supplier_page/      Transparent business, money, credit, action, toolbar, ledger and status icons
• icons/colored_tiles/      10 ready-to-use pastel background icon tiles
• badges/                   Recreated status badges as PNGs
• source_crops/             Exact region crops from the new Suppliers mockup, WITH their original rendered backgrounds
• reference/                Full source Suppliers-page PNG screenshot
• asset_preview.png         Preview sheet of selected assets

RECOMMENDED FOR APP INTEGRATION:
Use icons/navigation, icons/supplier_page, icons/colored_tiles, illustrations and branding for reusable UI.
Source crops are for visual matching and reference, not responsive interface components.

ABOUT SOURCE QUALITY:
The source was supplied as one raster mockup rather than separate design layers. It is not possible to recover the original independent vector files or guarantee pixel-perfect transparent extraction from an image. The clean icons and supplier hero art are REDRAWN PNG graphics based on the screen's style; the sidebar grocery art is reused from the same SmartKhata grocery visual theme. The exact screen crops preserve their original UI backgrounds.

All reusable icons/tiles are RGBA PNG with transparency outside the glyph/tile. Generic monochrome icons can be recolored for hover/active states in code. Supplier hero PNG is rendered at 520x330 and 1040x660.
